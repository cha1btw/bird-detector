# Bird Detector (YOLO26)

Проєкт для детекції птахів на відео. Модель `yolo26n` була донавчена на розпізнавання одного класу — `bird`.

## Інструкція зі встановлення залежностей

Для роботи проєкту необхідний Python 3.8+. Рекомендується використовувати віртуальне середовище.

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Команда для запуску навчання

Датасет має бути у форматі YOLO, а файл `data.yaml` — у корені проєкту.

```bash
python train.py
```

## Команда для обробки відео навченою моделлю

```bash
python predict_video.py --input examples/input.mp4 --output examples/output.mp4
```

## Інформація про використаний датасет

Для донавчання було використано відкритий датасет з платформи Roboflow.

- Клас: `bird` (1 клас)
- Формат розмітки: YOLO
- Розподіл: train / validation

## Отримані метрики на validation-вибірці

- mAP50: 0.949
- mAP50-95: 0.532

## Короткий опис проблем, що виникли, та можливих покращень

Проблеми:

- Дрібні птахи на складному фоні (наприклад, серед гілок або листя) можуть мати нижчий confidence через низьку роздільну здатність об'єкта відносно розміру кадру.
- Швидкий рух птахів на відео може створювати розмиття (motion blur), що ускладнює детекцію на окремих кадрах.

Можливі покращення:

- Збільшення тренувальної вибірки з додаванням специфічних аугментацій (Motion Blur, Random Brightness/Contrast).
- Використання більшої моделі (наприклад, `yolo26s` або `yolo26m`), якщо дозволяють обчислювальні ресурси пристрою для інференсу.
