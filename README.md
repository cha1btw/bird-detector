# Bird Detector (YOLO)

Проєкт для детекції птахів на відео із використанням попередньо навченої YOLO-моделі та донавчання на одному класі — `bird`.

Мета проєкту — показати end-to-end pipeline: підготовка даних, навчання, оцінка метрик, запуск інференсу на відео та збереження результату.

## Структура проєкту

```text
bird-detector/
├── README.md
├── requirements.txt
├── train.py
├── predict_video.py
├── download_dataset.py
├── download_model.py
├── data.yaml
├── yolo26n.pt
├── weights/
│   └── best.pt
├── examples/
│   ├── input.mp4
│   ├── output.mp4
│   └── output_test.mp4
└── videos/
```

## Вимоги

- Python 3.9+
- macOS / Linux / Windows
- 8 GB RAM або більше рекомендовано
- CUDA-підтримка необов'язкова для запуску інференсу на CPU

## Швидкий старт

### 1) Створити віртуальне середовище

```bash
python3 -m venv venv
source venv/bin/activate
```

### 2) Встановити залежності

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 3) Завантажити базову модель

```bash
python download_model.py
```

### 4) Завантажити датасет

Для повного навчального циклу потрібен датасет у форматі YOLO. У цьому репозиторії передбачено скрипт для завантаження датасету через Roboflow:

```bash
python download_dataset.py
```

Після завантаження в корені проєкту буде створений файл `data.yaml`.

### 5) Запуск навчання

```bash
python train.py
```

Або з кастомними параметрами:

```bash
python train.py --epochs 25 --batch 16 --imgsz 640 --device cpu
```

### 6) Запуск інференсу на відео

```bash
python predict_video.py --input examples/input.mp4 --output examples/output.mp4
```

Також можна вказати власні ваги і поріг довіри:

```bash
python predict_video.py --input examples/input.mp4 --output examples/output.mp4 --weights weights/best.pt --conf 0.25
```

## Дані

Для навчання було використано відкритий датасет із платформи Roboflow. Датасет містить розмітку YOLO для одного класу:

- `bird`
- кількість класів: 1
- розподіл: train / validation
- формат: YOLO

Файл `data.yaml` містить вказівки на шляхи до train/validation наборів і назви класів.

## Метрики на validation

Результати, отримані під час навчання на validation-вибірці:

- mAP50: 0.949
- mAP50-95: 0.532
- Precision: ~0.90+
- Recall: ~0.84+

Точні метрики можуть трохи варіюватися залежно від версії бібліотек, апаратного забезпечення та розбиття даних.

## Основні проблеми та покращення

### Проблеми

- Дрібні птахи на складному фоні можуть мати нижчу впевненість детекції через малий розмір об'єкта у кадрі.
- Швидкий рух птахів інколи додає blur і ускладнює точну локалізацію.
- Чутливість до освітлення та контрасту може впливати на якість детекції у складному середовищі.

### Можливі покращення

- Збільшити обсяг навчальної вибірки та додати аугментації: motion blur, brightness/contrast jitter, flip/rotate.
- Перевірити навчання на більшій моделі YOLO (наприклад, `yolov8s` або `yolov8m`), якщо потрібна більша точність.
- Додати ранню зупинку, кращу настройку LR та контроль якості після кожної епохи.
- Паралельно зберігати метрики у CSV/JSON для кращого аналізу експериментів.

## Підсумок

Цей проєкт демонструє повний pipeline для задачі детекції птахів на відео:

- збір/підготовка даних,
- навчання YOLO-моделі,
- оцінка якості,
- інференс на відео,
- збереження результату у файл.
